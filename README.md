# Крот

Премиальный мини-апп Telegram: своя социальная игра на вычисление чужого в
компании, на русском. Без заимствований. Та же тёплая, уютная дизайн-система,
что и у соседних игр семейства, со своим шпионским характером.

Все за столом знают одну общую локацию, и у каждого там своя роль. Все, кроме
одного. Этот один крот: он не знает, где все собрались, и должен прикинуться
своим. По кругу игроки задают друг другу короткие вопросы и слушают ответы.
Город ищет крота по неуверенным репликам, а крот вслушивается и пытается угадать
локацию. В конце голосуют: поймали крота, победил город; ошиблись, выиграл крот.

## Возможности

- Полный движок партии: раздача ролей, пошаговый допрос по кругу, модель
  подозрения, голосование, догадка крота. Авторитетный и детерминированный.
- 30 локаций в трёх наборах (Классика, Путешествия, Особые) по 7 ролей в каждой.
- Боты трёх уровней: Новичок, Знаток, Мастер (своя эвристика и темп раздумий;
  чем выше уровень, тем точнее стол вычисляет крота и тем убедительнее врёт
  бот-крот).
- Три режима: одиночная игра с ботами, быстрый онлайн (пустые места занимают
  боты под видом живых игроков) и игра с друзьями по коду из четырёх символов.
- Сервер авторитетен: раздача, ход допроса, голоса и итог считаются на сервере.
  Клиент опрашивает состояние. Локация крота и служебные сигналы клиенту не
  утекают.
- Премиальный интерфейс: полутёмный салон с лампой над столом, лента допроса,
  драматичная карта роли, плавные шторки и тосты. Звук на WebAudio, тактильный
  отклик Telegram.

## Структура

- `shared/` чистый игровой движок, контент локаций, боты, генерация реплик, ГСЧ
  и редактор вида для одного места (плюс тесты).
- `server/` Hono + better-sqlite3 + grammy: авторизация Telegram, профили,
  менеджер комнат с драйвером темпа, HTTP API и команды бота.
- `app/` React + Vite + Zustand: экраны, сцена, дизайн-система.

## Запуск локально

```
npm install
npm run dev:server   # сервер на :3000 (DEV MODE без BOT_TOKEN)
npm run dev:app      # клиент на :5179 с прокси на сервер
```

Проверки:

```
npm run typecheck
npm test
npm run build
```

## Деплой

Развёртывание на Railway (Nixpacks, Node 22). Нужные переменные окружения см. в
`.env.example`: `BOT_TOKEN`, `APP_URL`, `BOT_USERNAME`, `WEBHOOK_SECRET`,
`JWT_SECRET`, `DATA_DIR`. В продакшене без `JWT_SECRET` сервер не стартует, а без
`BOT_TOKEN` вход через Telegram закрыт (fail-closed).
